# v0.1.0-alpha

First public CauseScope alpha. Python package version: `0.1.0a0`.

- Local YAML-driven configuration experiments with explicit execution opt-in.
- Six bounded search strategies, delta debugging and fresh confirmation.
- Optional fixed-sample holdout analysis with documented assumptions.
- Standalone HTML/JSON evidence, a guided spec creator and fresh reproduction.
- Optional stdio MCP integration with frozen plans and one-use CLI approvals.
- MIT license, a synthetic example, regression tests and pinned external adapters.

Alpha limitations: interfaces and evidence formats may change; searches can be
inconclusive; observed 1-minimality does not prove an internal root cause. Targets
run with inherited OS permissions, so use disposable local programs and test data.
Review generated reports before sharing.

The Codex-only versus Codex + CauseScope A/B evaluation remains incomplete.
No superiority or performance-improvement claim is established. Historical
experimental outputs and private evaluation material are excluded from this snapshot.

See [installation and example](README.md) and the
[executed verification and remaining blockers](docs/PUBLICATION_STATUS.md).
